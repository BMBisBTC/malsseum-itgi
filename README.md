# 말씀잇기

개역한글 성경의 단어와 구절을 익히는 웹 학습 게임입니다. 125개 단어·인물·장소와 성경 인물 50명을 뜻 퀴즈, 말씀 암송, 음절 퍼즐로 만나 보세요.

## 게임

- 오늘의 단어를 구절과 함께 학습
- 구약·신약 인물 50명의 소개와 대표 구절을 검색하며 학습
- 단어 뜻과 대표 원어를 연결하는 퀴즈
- 빈칸, 단계별 암송, 내 목소리 녹음
- 한 단어 음절 퍼즐과 교차 낱말 퍼즐
- 인물·장소를 포함한 주제별 말씀 여정

학습 진도와 묵상 기록은 이용 중인 브라우저에 저장되며 다른 사람과 공유되지 않습니다. 음성 녹음은 서버로 전송하지 않습니다.

## 본문

본문: 『성경전서 개역한글판』(1961), 대한성서공회
